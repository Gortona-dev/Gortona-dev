## About Me

I'm a developer from Capivari, Sao Paulo, Brazil, focused on building practical software for automation, data analysis and system integration.

My work combines back-end development, relational databases, APIs, dashboards and operational workflows. I enjoy creating solutions that reduce manual work, organize information and help teams make better decisions with data.

- Systems Analysis and Development student at IFSP.
- Experience as Data Analyst (JR) / Web Developer at M&M Souza.
- Focused on Java, Spring Boot, Python, Flask, SQL, Power BI, Pandas and REST APIs.
- Interested in automation, integrations, cloud technologies and Microsoft Power Platform.
